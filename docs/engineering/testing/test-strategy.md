# Test Strategy

## Test layers

Digital StarGate applies layered verification:

- **unit tests** for isolated logic;
- **schema and contract tests** for interfaces and events;
- **integration tests** for service and device interactions;
- **workflow tests** for complete automation sequences;
- **operational tests** for monitoring, backup and recovery;
- **acceptance tests** for release objectives.

## Risk-based depth

Safety, roof control, weather decisions, power recovery and autonomous shutdown require the highest test depth and independent review.

## Evidence

Test evidence must identify the version tested, environment, inputs, result, anomalies and responsible reviewer.
