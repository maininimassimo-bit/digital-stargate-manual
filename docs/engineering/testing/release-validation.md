# Release Validation

## Validation checklist

Before approval, a release must demonstrate:

- successful clean build;
- completion of required test suites;
- compatibility with supported devices and software versions;
- successful configuration migration where applicable;
- verified monitoring and alerting;
- backup and rollback readiness;
- updated user, operator and architecture documentation.

## Post-release verification

After deployment, verify service health, telemetry flow, safety evaluation, scheduler readiness, storage availability and a representative end-to-end workflow.
