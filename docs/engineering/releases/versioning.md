# Versioning

## Scheme

Digital StarGate uses semantic versioning for released software and platform components:

```text
MAJOR.MINOR.PATCH
```

- `MAJOR` indicates incompatible behaviour or interface changes.
- `MINOR` adds backward-compatible capability.
- `PATCH` contains backward-compatible corrections.

Documentation baselines and architecture releases may use aligned release identifiers even when no executable package is produced.

## Pre-release identifiers

Pre-release versions may use suffixes such as `-alpha`, `-beta` or `-rc.1`. They are not considered production baselines until formally promoted.
