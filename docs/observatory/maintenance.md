# Observatory Maintenance

## Frequenze consigliate

| Frequenza | Attività |
|---|---|
| Prima di ogni sessione | verifica meteo, sensori, spazio disco, connettività |
| Mensile | test apertura/chiusura, park, failover WAN, log errori |
| Trimestrale | backup configurazioni, aggiornamenti controllati, ispezione cavi |
| Semestrale | test recovery completo, verifica UPS, pulizia ottiche esterne |
| Annuale | inventario, revisione asset, verifica meccanica e sicurezza |

## Regola di change management

Nessun aggiornamento di firmware o driver durante una finestra osservativa critica senza piano di rollback.
