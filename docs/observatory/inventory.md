# Observatory Inventory

## Campi minimi

- Asset ID
- vendor e modello
- numero seriale
- firmware
- driver
- indirizzo IP
- alimentazione
- posizione fisica
- responsabile
- data ultima verifica
- stato operativo

## Dati sensibili

Seriali, credenziali, chiavi VPN e dati di accesso non devono essere pubblicati nella documentazione aperta. Devono essere conservati in un secret store o registro protetto.
