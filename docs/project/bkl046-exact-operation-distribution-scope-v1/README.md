# BKL-046 · Perimetri operativi e consegna

Il fascicolo per i revisori contiene i 70 membri di Stream34 v11 e consente di verificare le impronte senza eseguire il launcher. Il soggetto storico H126 riportava un'approvazione d'implementazione e un arresto preliminare per memoria insufficiente. In questo audit i due riscontri storici sono stati confrontati fra loro. Il verbale originale non è stato riautenticato. H126 e Stream34 v11 hanno impronte diverse.

| Passo aperto | Evidenza necessaria |
| --- | --- |
| Revisione Stream34 v11 | Verbale ARB e attestazione firmata sul soggetto `0b029846da0412875e26595e2ead8361bc35fcef2c882ec2be95303b9582bdd1`. Dopo un ARB favorevole, verbale RQ con l'impronta esatta dell'ARB e attestazione firmata. Il trust deve avere una SHA-256 ottenuta tramite il canale autenticato. |
| Avvio della prova Stream34 | Autorizzazione operativa e iscrizione previste dal launcher, preflight nel processo effettivo e ammissione del coordinatore. Le misure diagnostiche di commit riguardano il processo di collaudo. |
| Consegna integrale v1.171 | Decisione del titolare sul perimetro dei contenuti e sulla destinazione GitHub autorizzata. Il repository attuale è pubblico e ospita l'indice. Dopo il trasferimento serve una rilettura indipendente degli oggetti remoti e la ricostruzione verificata. |

La PR #627 era aperta con zero oggetti di review. Nel fascicolo locale non erano presenti verbali Stream34 v11, attestazioni d'origine o file di trust. I due reperimenti hanno perimetri distinti. Il kit locale conserva le fonti fissate per una verifica senza rete. Il rapporto pubblico contiene solo impronte e riscontri di stato. Zero avvii PixInsight e zero chiusure scientifiche.
