# Project Governance Center

Il Project Governance Center è il punto di accesso alle regole che governano lo sviluppo e la pubblicazione del Digital StarGate Enterprise Portal.

## Documenti canonici

- [Enterprise Architecture Context](ENTERPRISE_ARCHITECTURE_CONTEXT.md) — baseline e bootstrap di ogni nuova sessione.
- [Development Workflow](DEVELOPMENT_WORKFLOW.md) — flusso milestone per milestone.
- [Coding Standards](CODING_STANDARDS.md) — standard JavaScript, CSS e UI.
- [Release Playbook](RELEASE_PLAYBOOK.md) — test, commit, deployment e acceptance.
- [Technical Debt Register](TECHNICAL_DEBT.md) — debito tecnico esplicito e governato.
- [Decision Log](DECISION_LOG.md) — decisioni operative che non richiedono ancora un ADR.
- [Project Backlog](BACKLOG.md) — backlog prioritizzato del portale.

## Regola di prevalenza

Questi documenti non sostituiscono Architecture Package, ADR, assessment, evidence, roadmap o release note approvate. In caso di divergenza prevalgono le fonti architetturali e le evidenze versionate.

## Aggiornamento

Ogni milestone che modifica baseline, standard, release state, debito o priorità deve aggiornare il documento corrispondente nello stesso change set.
