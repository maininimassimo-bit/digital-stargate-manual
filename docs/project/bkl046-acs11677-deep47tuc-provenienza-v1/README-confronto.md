# BKL-046 — Provenienza del catalogo DEEP47TUC

Il catalogo pubblico contiene 51.480 sorgenti con fotometria PSF F606W e F814W. Il controllo ha letto la testata primaria completa del mosaico F606W e verificato le 234 voci `DnnnDATA` per 117 esposizioni, ciascuna con entrambi i chip.

Il mosaico pubblicato e la replica di `jb6v01010` condividono cinque delle sei acquisizioni HST. Nel mosaico DEEP47TUC compaiono i prodotti FLT, mentre la replica usa i corrispondenti FLC. Il riscontro si basa sugli identificativi delle stesse esposizioni grezze, compresa `jb6v01e0q`. Per questo campo, il catalogo può affiancare un riscontro descrittivo. La stima indipendente del flusso delle sorgenti sature richiede esposizioni distinte.
