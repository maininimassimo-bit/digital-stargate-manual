## Accepted scope

BKL-032 is closed as a deterministic, explainable, fail-closed decision-support capability. It consumes normalized evidence and returns only `GO`, `NO_GO` or `INDETERMINATE`. It does not schedule, select targets automatically, command apparatus or replace local physical interlocks.

## Owner-approved policy

- `GO` requires current forecast, current astronomy, setup compatibility and passing read-only telemetry for weather, dome, mount, camera, power, network and EAGLE health.
- Maximum forecast/readiness freshness is six hours.
- `NO_GO` applies to rain > 0, mean wind > 15 km/h, gust > 20 km/h, cloudiness > 50%, humidity > 90%, or dew-point margin ≤3 °C. DLG-144 (2026-09-27) supersedes the dew-point component of DLG-059; the other limits are unchanged.
- Equality at the existing inclusive thresholds passes, except the dew-point margin boundary: exactly 3 °C is `NO_GO`; only >3 °C passes.
- Missing, stale, conflicting or unavailable mandatory evidence produces `INDETERMINATE`, including when another signal is blocking.
- Thresholds apply to both opening and continuation decision support.

## Owner policy amendment — 2026-09-27 (DLG-144)

The owner changed the BKL-032 readiness dew-point margin from `<10 °C` blocking
to `≤3 °C` blocking. The read-only evaluator and Status presentation implement
the amended calculation `ambient temperature − dew point`; this changes only
the dew-point threshold. It does not change BKL-032 state semantics, other
weather thresholds, device control, local physical interlocks or Safety
Authority. This repository update does not authorize runtime activation or
change any live source/transport gate.
