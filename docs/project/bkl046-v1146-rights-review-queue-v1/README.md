# BKL-046 · Registro di revisione della conoscenza storica v1.146

Il registro identifica gli intervalli esatti dei byte del JSON storico. Copre il prefisso e tutte le 141 sezioni serializzate. Per ciascuno dei 708 rapporti incorporati verifica l'impronta dell'intervallo rispetto all'indice congelato e registra i conteggi dei marcatori e dei riscontri con l'inventario precedente. Il riepilogo pubblico conserva soltanto conteggi e impronte.

I 14 rapporti con riscontri precedenti richiedono una verifica del perimetro effettivamente coperto. Per 209 rapporti con marcatori e senza riscontro precedente il registro identifica il punto da esaminare. Anche i 485 rapporti senza marcatori e senza riscontro precedente restano in revisione. Le tre code assegnano priorità al lavoro e non attestano diritti di distribuzione.

Per riprodurre usare Python 3.12 con il protocollo, la capsula storica, l'indice degli incorporati, un nuovo percorso per il registro locale e un nuovo percorso per il riepilogo. La directory del riepilogo ospita anche un temporaneo durante la lettura. Registro e riepilogo non includono il testo individuato dalle espressioni di ricerca. Il registro dettagliato resta custodito sullo storage autorizzato.
