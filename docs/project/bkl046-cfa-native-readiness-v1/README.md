# BKL-046 — Precondizioni per la prova nativa CFA

Su DSG-Shared sono stati riletti i 21 membri del soggetto CFA v4 e verificati i sei file installati del coordinatore indicati dal soggetto. La prova in sola lettura con il token ordinario conferma che il launcher e il modulo di attivazione in staging sono scrivibili. Il modulo esporta ancora una configurazione nulla. La PR #627 risultava priva di revisioni GitHub al controllo. Le verifiche di integrità del coordinatore e i collaudi offline del launcher riguardano ambiti distinti dalle approvazioni operative della candidata.

Per la prova servono ricevute ARB e RQ indipendenti sul soggetto esatto, con la ricevuta RQ vincolata a quella ARB. Servono poi un'installazione gestita protetta dal chiamante, la configurazione con le chiavi di ruolo effettive e l'ammissione dal registro canonico. Durante questo controllo PixInsight era chiuso e non è stata richiesta ammissione.
