# Data Quality Validation

## Controlli minimi

- file leggibile;
- header coerente;
- dimensioni attese;
- checksum disponibile;
- timestamp plausibile;
- associazione a camera e sessione;
- classificazione raw/calibration;
- assenza di duplicati tecnici.

## Controlli scientifici opzionali

- FWHM;
- eccentricità;
- numero di stelle;
- fondo cielo;
- saturazione;
- drift;
- qualità di guida;
- presenza di nuvole o gradienti anomali.
