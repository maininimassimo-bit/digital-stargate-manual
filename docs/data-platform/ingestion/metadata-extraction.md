# Metadata Extraction

## Fonti

- header FITS;
- manifest della sessione;
- configurazione strumenti;
- stato meteo;
- stato della montatura;
- parametri di acquisizione;
- log applicativi.

## Metadata minimi

Target, data e ora UTC, durata, filtro, binning, gain, offset, temperatura sensore, camera, telescopio, focale, coordinate, identificativo sessione e checksum.

I valori mancanti devono essere marcati esplicitamente e non ricostruiti senza una regola tracciata.
