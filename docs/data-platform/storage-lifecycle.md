# Storage and Data Lifecycle

## Zone dati

- **Landing**: file appena ricevuti, non ancora validati;
- **Raw**: dati originali validati e immutabili;
- **Calibration**: librerie di calibrazione controllate;
- **Working**: prodotti temporanei o intermedi;
- **Curated**: prodotti scientifici consolidati;
- **Published**: prodotti destinati a condivisione o divulgazione;
- **Archive**: conservazione di lungo periodo.

## Politiche

I dati raw e i metadata essenziali hanno priorità massima di conservazione. I prodotti temporanei possono essere rigenerati e sono soggetti a retention limitata. I prodotti finali devono conservare lineage, versione del software e parametri di elaborazione.
