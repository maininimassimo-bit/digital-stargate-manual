# Runbook — Storage Pressure

1. misurare capacità libera e tasso di crescita;
2. bloccare cancellazioni manuali non governate;
3. identificare cache e temporanei eliminabili;
4. verificare backup dei dati candidati all'archiviazione;
5. applicare le classi di retention;
6. liberare spazio in modo tracciato;
7. verificare la ripresa di ingestion e pipeline;
8. aggiornare capacity forecast e incidente.
