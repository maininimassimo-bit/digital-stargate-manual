# Processing Pipeline Architecture

Le pipeline trasformano dati raw in prodotti scientifici mantenendo tracciabilità completa.

## Stadi tipici

1. selezione input;
2. calibrazione;
3. cosmetic correction;
4. debayer, se applicabile;
5. star alignment;
6. normalizzazione;
7. integrazione;
8. post-processing scientifico;
9. quality assessment;
10. pubblicazione nel catalogo.

Ogni stadio deve dichiarare versione software, parametri, input, output, log ed esito.
