# Processing Profiles

I profili descrivono pipeline ripetibili per categorie omogenee.

| Profilo | Ambito |
|---|---|
| LRGB Deep Sky | acquisizioni mono LRGB |
| SHO Narrowband | palette H-alpha, OIII, SII |
| OSC Broadband | camere a colori con filtro broadband |
| OSC Dual Band | acquisizioni con filtri dual-band |
| Lunar | acquisizioni lunari e stacking ad alta risoluzione |
| Transient Detection | confronto immagini e rilevazione variazioni |

Ogni profilo deve essere versionato e associato ai processing run.
