# Calibration and Integration

## Calibrazione

Le librerie di bias, dark, flat e dark-flat devono essere identificate per camera, temperatura, gain, offset, binning, filtro e periodo di validità.

## Integrazione

L'integrazione deve registrare criteri di selezione, normalizzazione, rejection, weighting e numero di frame utilizzati o esclusi.

I master frame e le immagini integrate sono prodotti versionati e non devono sostituire i dati raw.
