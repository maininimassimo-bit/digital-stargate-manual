# Naming Conventions

I nomi dei file devono essere leggibili ma non costituiscono l'identificativo primario.

Formato raccomandato:

```text
<target>_<dateUTC>_<camera>_<filter>_<exposure>s_<binning>_<sequence>.<ext>
```

Esempio:

```text
M51_20260415_QHY695A_HA_600s_BIN2_001.fits
```

I caratteri devono essere compatibili con Windows, Linux e strumenti scientifici utilizzati nel progetto.
