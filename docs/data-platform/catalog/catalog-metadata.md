# Catalog and Metadata

Il catalogo fornisce una vista ricercabile dei dati senza dipendere direttamente dalla struttura delle cartelle.

## Criteri di ricerca

- target;
- data e sessione;
- strumento;
- filtro;
- tempo di posa;
- stato di elaborazione;
- qualità;
- tipo di prodotto;
- versione della pipeline;
- stato di pubblicazione.

Il catalogo non sostituisce l'archivio: contiene riferimenti, metadata, relazioni e stato del ciclo di vita.
