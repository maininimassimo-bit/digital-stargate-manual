# Retention and Archiving

## Classi di conservazione

| Classe | Contenuto | Regola indicativa |
|---|---|---|
| R1 | dati raw validati | conservazione permanente o massima disponibile |
| R2 | calibration master | lunga durata, con riesame periodico |
| R3 | prodotti finali | lunga durata |
| R4 | intermedi riproducibili | retention limitata |
| R5 | cache e temporanei | cancellazione automatica |

Le durate effettive devono essere definite in base alla capacità disponibile e al valore scientifico.
