# Data Governance

## Responsabilità

- il Data Owner definisce finalità e priorità;
- il Data Steward mantiene qualità, metadata e regole;
- il Platform Owner garantisce disponibilità e sicurezza;
- l'operatore verifica le eccezioni;
- le pipeline producono evidenze tecniche automatiche.

## Controlli

Classificazione, qualità, lineage, retention, accesso, backup, export e cancellazione devono essere governati da regole documentate.
