# Data Access and Security

## Principi

- minimo privilegio;
- separazione tra accesso operativo e amministrativo;
- protezione dei dati raw da modifiche accidentali;
- tracciamento delle operazioni distruttive;
- accesso remoto esclusivamente tramite canali autorizzati;
- verifica periodica di backup e restore.

Le credenziali e i segreti non devono essere memorizzati nei metadata scientifici o nei file di documentazione.
