# Capitolo 6 – Computer di controllo EAGLE

**Codice:** DSG-TM-001-06  
**Revisione:** 0.1 Draft

## 6.1 Ruolo

L’EAGLE è il nodo centrale di elaborazione, connettività USB, alimentazione e controllo remoto.

## 6.2 Software principali

- Windows.
- N.I.N.A.
- CPWI.
- PHD2.
- ASTAP.
- ASCOM Platform.

## 6.3 Gestione USB

Mantenere una mappatura stabile delle porte, evitare hub non alimentati e disabilitare la sospensione selettiva USB.

## 6.4 Backup

Eseguire backup periodici di profili, driver, sequenze, log e configurazioni.
