## 1. Scopo

Consolidare l'evidence operativa AP-013 disponibile nel repository e determinare se il percorso di ingestion scientifica attualmente autorizzato soddisfa i criteri di accettazione senza estendere impropriamente il risultato a capability non validate.

## 2. Baseline verificata

Il percorso operativo accettato è:

```text
NINA source on EAGLE
  -> DSG OneDrive Export Agent
  -> OneDrive transport/staging
  -> DSG OneDrive Import Agent
  -> AP-013 COPY_ONLY Engine
  -> F:\Astrofotografia
```

Regole obbligatorie:

- source immutabile;
- no overwrite;
- SHA-256 end-to-end;
- manifest READY pubblicato dopo verifica;
- import solo da payload localmente disponibile e verificato;
- nessun cleanup automatico;
- OneDrive non è repository autorevole.

## 5. Acceptance boundary

`Passed` significa che il percorso operativo di ingestion scientifica attualmente autorizzato è stato verificato entro i limiti dichiarati.

Non significa che:

- l'intero archivio storico sia migrato;
- backup/restore a lungo termine siano certificati;
- RPO/RTO siano approvati;
- tutti i processing run PixInsight siano automaticamente tracciati;
- il sistema sia certificato per batch superiori a 30 o per 1000 file/run.
