# AUTO-005 — Guiding Startup

## Passi

1. connessione a PHD2;
2. selezione profilo;
3. loop camera guida;
4. scelta stella;
5. calibrazione, se necessaria;
6. avvio guida;
7. attesa stabilizzazione RMS;
8. conferma stato `Guiding`.

## Errori tipici

- camera guida non disponibile;
- stella non selezionabile;
- calibrazione fallita;
- pulse guide failed;
- RMS oltre soglia.

Ogni errore deve essere correlato alla sessione e al target corrente.
