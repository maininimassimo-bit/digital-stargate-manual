# Night Scheduler

## Input

- target e priorità;
- finestra di osservabilità;
- quota minima;
- distanza dalla Luna;
- durata prevista;
- filtri richiesti;
- condizioni meteo minime;
- stato degli asset.

## Decisioni

Lo scheduler ordina i target in base a:

1. sicurezza;
2. visibilità;
3. priorità scientifica o operativa;
4. efficienza dei cambi filtro e dei movimenti;
5. tempo residuo della notte.

## Output

- piano di sessione;
- sequenza target;
- finestre temporali;
- condizioni di skip;
- piano di shutdown.
