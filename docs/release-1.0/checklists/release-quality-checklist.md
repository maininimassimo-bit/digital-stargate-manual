# Release Quality Checklist

## Repository state

- [ ] Correct branch selected.
- [ ] All intended files committed.
- [ ] Working tree clean.
- [ ] Commit history reviewed.
- [ ] Release version agreed.

## Build validation

- [ ] Virtual environment activated.
- [ ] Dependencies installed from approved source.
- [ ] `mkdocs build --strict` completed successfully.
- [ ] Generated site reviewed locally.
- [ ] No new build errors introduced.

## Architecture consistency

- [ ] Domain indices present.
- [ ] Registries reviewed.
- [ ] Naming conventions consistent.
- [ ] Cross-domain dependencies documented.
- [ ] Known deviations recorded.

## Approval

- [ ] Architecture owner approval.
- [ ] Documentation owner approval.
- [ ] Release manager approval.
- [ ] Product owner approval.
