# Documentation Review Checklist

- [ ] Every navigation entry points to an existing file.
- [ ] Every major section has an overview page.
- [ ] Document titles match navigation labels.
- [ ] Relative links use correct paths.
- [ ] Tables render correctly.
- [ ] Code blocks specify an appropriate language where useful.
- [ ] Terminology is consistent across domains.
- [ ] Status labels are current.
- [ ] Placeholder text has been removed.
- [ ] Known issues are explicitly documented.
- [ ] Release notes reflect the actual repository contents.
- [ ] Changelog reflects the actual release scope.
