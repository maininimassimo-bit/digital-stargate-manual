## Baseline control

The baseline is controlled through:

- Git commit history;
- branch protection and review;
- MkDocs build validation;
- release checklists;
- release tag `v1.0.0`;
- documented known issues.

## Change policy

After release tagging, changes to the baseline must be introduced through a new branch and assigned to a future release or patch version.
