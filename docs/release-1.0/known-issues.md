# Known Issues

## KI-001 — Legacy enterprise anchors

**Status:** Open  
**Severity:** Low  
**Impact:** Informational messages during MkDocs build.

Several links in enterprise registries, governance and roadmap documents reference anchors that are not generated by the current headings.

### Current effect

- `mkdocs build --strict` completes successfully.
- Site generation is not blocked.
- Some deep links may not navigate to the intended subsection.

### Planned remediation

- inventory all unresolved anchors;
- normalize heading identifiers;
- add explicit HTML anchors where required;
- validate links in Release 1.1 or a dedicated patch.

## KI-002 — MkDocs 2.0 ecosystem warning

**Status:** Monitor  
**Severity:** Medium  
**Impact:** Potential future incompatibility.

Material for MkDocs reports a warning regarding expected MkDocs 2.0 compatibility changes. The current Release 1.0 baseline should preserve tested dependency versions until a migration strategy is defined.
