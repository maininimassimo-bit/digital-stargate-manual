# Next Release Roadmap

## Target: Release 1.1

Release 1.1 should convert the documentation baseline into a more executable engineering platform.

## Candidate workstreams

1. Resolve legacy anchor and link issues.
2. Introduce automated documentation validation in CI.
3. Add architecture decision records.
4. Create machine-readable registries.
5. Implement infrastructure-as-code foundations.
6. Prototype observatory automation adapters.
7. Define executable scientific data pipeline contracts.
8. Add telemetry dashboards and operational KPIs.
9. Expand security threat modelling.
10. Formalize backup and disaster-recovery tests.

## Entry criteria

Release 1.1 planning starts after:

- Release 1.0 is tagged;
- known issues are accepted;
- ownership is assigned;
- backlog priorities are approved.
