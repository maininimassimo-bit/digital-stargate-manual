# INFRA-000 — Infrastructure Registry

## Purpose

The infrastructure registry identifies the principal technical domains and operational responsibilities of Digital StarGate.

| ID | Domain | Scope | Owner | Status |
|---|---|---|---|---|
| INFRA-001 | Connectivity | Starlink, LTE, LAN, VPN and failover | Platform Operations | Active |
| INFRA-002 | Compute | EAGLE3 and supporting runtime hosts | Platform Operations | Active |
| INFRA-003 | Storage | Local acquisition, staging and archive storage | Data Operations | Active |
| INFRA-004 | Power | UPS, protected outlets and shutdown controls | Observatory Operations | Active |
| INFRA-005 | Monitoring | Health, telemetry, logging and alerts | Platform Operations | Active |
| INFRA-006 | Backup | Configuration and documentation backup | Platform Operations | Active |
| INFRA-007 | Security | Remote access, credentials and hardening | Security Owner | Active |
| INFRA-008 | Recovery | Service restoration and disaster recovery | Platform Operations | Active |

## Governance

Each infrastructure domain must define:

- accountable owner;
- operational status;
- dependencies;
- monitoring coverage;
- backup and recovery requirements;
- change and maintenance rules.
