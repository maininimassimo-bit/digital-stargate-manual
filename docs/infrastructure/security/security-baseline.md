# Security Baseline

## Baseline controls

The infrastructure security baseline includes:

- VPN-only remote administration where practical;
- unique credentials for administrative services;
- least-privilege access;
- removal of default passwords;
- controlled firewall rules;
- regular operating system and application updates;
- protected backup copies;
- logging of administrative changes;
- documented credential recovery procedures.

## Local resilience

Safety functions must remain available when Internet services are unavailable. Cloud dependencies must never be the only mechanism capable of initiating an emergency shutdown.
