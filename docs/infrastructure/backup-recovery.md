# Backup and Recovery

## Backup scope

The following items require backup:

- MkDocs documentation repository;
- automation configuration;
- device profiles;
- NINA profiles and sequences;
- network configuration exports;
- scripts and operational tools;
- asset and maintenance records;
- security recovery material stored according to policy.

## Recovery priorities

1. restore safety controls;
2. restore local network and remote access;
3. restore primary compute services;
4. restore device integrations;
5. restore automation workflows;
6. restore non-critical tooling.

## Recovery evidence

A backup is not considered effective until restoration has been tested. Recovery tests must record:

- date;
- restored component;
- recovery time;
- issues encountered;
- corrective actions.
