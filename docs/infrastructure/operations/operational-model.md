# Operational Model

## Operating modes

The infrastructure supports four operating modes:

| Mode | Description |
|---|---|
| Normal | All required services are available |
| Degraded | One or more non-safety functions are unavailable |
| Safe | Observation is suspended and assets are protected |
| Recovery | Controlled restoration after an incident |

## Daily operations

Routine operations include:

- connectivity verification;
- service health review;
- disk capacity check;
- safety sensor validation;
- backup status review;
- incident and maintenance log review.

## Change control

Infrastructure changes must include:

- purpose and affected components;
- rollback plan;
- validation steps;
- maintenance window where required;
- documentation update;
- post-change verification.
