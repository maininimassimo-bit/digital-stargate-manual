# Maintenance Model

## Maintenance categories

- preventive maintenance;
- corrective maintenance;
- firmware and software maintenance;
- security maintenance;
- capacity maintenance;
- recovery testing.

## Maintenance record

Each activity should record:

| Field | Description |
|---|---|
| Date | Execution date |
| Asset or service | Scope of maintenance |
| Activity | Work performed |
| Result | Successful, partial or failed |
| Evidence | Log, screenshot or test result |
| Follow-up | Additional action required |

Safety-related maintenance must be validated before unattended operation resumes.
